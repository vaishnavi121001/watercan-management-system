# 💧 WaterCan Management System

### Water Delivery & Customer Management Platform

A Django-based management system designed to streamline water can delivery operations, customer management, inventory tracking, and delivery workflows.

---

## 📖 Overview

The WaterCan Management System helps manage the complete lifecycle of water can distribution, from customer registration and order management to delivery tracking and inventory monitoring.

The platform simplifies day-to-day operations and improves efficiency through centralized management and automated workflows.

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/vaishnavi121001/watercan-management-system.git
```

### Navigate to Project

```bash
cd watercan-management-system
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / Mac

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Migrations

```bash
python manage.py migrate
```

### Start Server

```bash
python manage.py runserver
```
